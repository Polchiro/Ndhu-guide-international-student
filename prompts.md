# # Build an NDHU International Student Guide Website

Read `README.md` in this repository, then build a polished, mobile-friendly, one-page website for international freshmen at National Dong Hwa University (NDHU) who do not speak Chinese.

Create `index.html`, `style.css`, and `script.js` if needed. Work directly in the repository.

## 1. Content Accuracy

- Use `README.md` as the single source of truth. Preserve all facts, wording, prices, dates, times, addresses, place names, and contact details. Fix only obvious grammar and spelling mistakes.
- Preserve every original link and make it clickable.
- Display every `[CHECK: ...]` note with an `Unverified` badge, keeping the note text unchanged.
- Never invent facts or Mrs. Jenny's contact information.
- In your final response, list everything displayed on the website that is not directly stated in the README, including interface text and generated links.

## 2. Design

Create a unique, professional university welcome-guide aesthetic: calm blue or teal accents, warm neutral backgrounds, rounded cards, generous whitespace, subtle shadows, and readable system fonts.

Avoid generic templates, excessive gradients, emojis, and unnecessary animations. Make the site feel welcoming, trustworthy, and impressive enough for a university project.

Include:

- A hero header titled **Getting Started at NDHU**, with a short subtitle for international students.
- A sticky navigation bar linking to all five sections, with a collapsible mobile menu.
- Five numbered, card-style sections matching the README headings.
- A simple footer containing: "Prices, times, and dates may change, so check official sources."
- A Back to top button.

## 3. Content Layout

- **Arriving at NDHU:** Display the airport journey as a visual step-by-step route. Put Route A and Route B side by side on desktop and stack them on mobile. Separate train booking, ARC instructions, arrival advice, bicycle information, and Mrs. Jenny's contact details where available.
- **Phone Plans:** Present contract and prepaid options clearly, with a readable comparison table, official Chunghwa Telecom links, and a highlighted hotspot warning.
- **Dorm Life:** Keep the advice concise, readable, and practical.
- **Food and Groceries:** Separate cooking and eating-out advice. Use a responsive table for food places, with a `Copy` button beside every Chinese name and a Google Maps search link for each name.
- **Course Selection:** Display course dates in a responsive table and highlight the official NDHU academic calendar link.

Preserve all original content and table values from the README.

## 4. Functionality and Accessibility

- Use semantic HTML, vanilla JavaScript, and responsive CSS. No unnecessary frameworks or external font downloads.
- Make the mobile menu, navigation links, copy buttons, and Back to top button functional.
- Provide clear feedback when text is copied.
- Ensure readable text of at least 16px, strong contrast, visible keyboard focus, accessible buttons, and reduced-motion support.
- Make tables scroll horizontally on small screens without causing page overflow.
- Reuse available local images without inventing missing asset paths.

## 5. Final Checks

Before finishing, verify that all five sections, original links, tables, and interactions work. Test desktop and mobile layouts if testing tools are available.

In your final response, summarize the files changed, implemented features, tests performed, and any content that could not be included as requested. Separately list all website content not directly supported by the README.

**Priority:** Create a beautiful, practical website that helps international students navigate their first weeks at NDHU while keeping every factual detail faithful to the README.
